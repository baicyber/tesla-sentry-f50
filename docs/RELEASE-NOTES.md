# 2.3 → 2.8.37 大版本更新（重点）

> 覆盖 2.4 ~ 2.8 的主要里程碑，当前版本 **2.8.37**（2026-11-09）。
> 一句话：从「能看」变成「点开就播、插上就用、不烫手」。

## 播放：干等二十秒 → 点开即播

- **首开不再等转码**：`/media` 没命中缓存时立即用已有压缩档（都没有才用原画）发首帧，转码全部挪到后台；首字节从 19~25s 降到 0.005s 量级，切段或下次打开自动用上目标档位（2.8.36）。
- **默认单路播放**：点开事件只加载触发摄像头那一路，画面下方的切换条再选前视 / 后视 / 左 B 柱 / 右 B 柱 / 全览，点哪路才加载哪路，切换保留播放进度；全览仍是 4 路 2×2 / 6 路 3×2 同步校正（2.8.32）。
- **缓冲慢的三层根因一起修**：预热只盖触发段（原来转错片段）、单路不再多路独占链路、码率回到公网 / 5G 上行容量内；服务端能感知浏览器 `abort` 断连，不再被废弃连接占死并发名额，修掉「四格永远缓冲中」（2.8.26~2.8.30）。
- **默认画质统一 480p**：播放、飞书推送、导出同一档位，手动改过会记住选择（2.8.33）。
- **自动定位触发时刻**：不再固定播最后一段，而是落到触发时刻所在那一分钟、从触发前 5 秒起播（2.8.20）。
- **实时预览画框按片源比例**：单路 1280×960 的 4:3 片源不再被 16:9 框裁切，全览格子也按第一路比例计算（2.8.36）。

## 温控：只预热真正会被点开的片段

- 后台预转白名单收紧为**哨兵 + 手动保存**的触发路 ± 相邻段（每事件 3 个文件），且只在没人看视频时跑。
- **行车记录 / 准实时预览不再预热**：这类片段每分钟新增、很快滚动淘汰，预转出来的 480p 缓存几乎立刻作废；实测预转期间 2 路 ffmpeg 常驻，核心温度基线 63→70°C、尖峰 87°C。取消后 ffmpeg 归零、loadavg 3.6→1.4、温度稳定 68~71°C（2.8.37）。
- 注意：**取消的只是「提前预转」，不是转码能力** —— 真点开时照常按需后台转码，服务端还会兜底拦截旧页面缓存提交的预热请求。
- 存储卡折叠区新增一行系统状态：CPU 温度 / CPU 占用 / 内存，改成三等分指标格，文字不再被折叠箭头挡住（2.8.34、2.8.35）。

## 部署：插车就能录，不用再点格式化

- `install.sh` 部署时直接写入车机同款 exFAT 元数据和 `TeslaCam/{RecentClips,SavedClips,SentryClips,EncryptedClips}`，插车直接显示容量并开始录制，**不再弹「格式化 USB 设备」**（2.8.35）。
- 旧版全零空盘重装会自动补写；镜像里已有数据则拒绝覆盖；`--size` 超过 128G 会回退空白盘，由车机格式化一次。
- 默认镜像 170G → **64G**，并加磁盘余量校验；卸载脚本补齐服务 / cron / rc.local 清理。
- 容量条改按**卷内实际写入量**计（不再永远满格），按占用比例配色：绿 <30% / 蓝 30~85% / 红 >85%（2.8.21、2.8.22）。

## 实时预览与文件管理

- 新增**准实时预览**：利用循环录制的 1 分钟延时直播，升为与其它分类同级的页签，支持全览多画面和原画 / 720p / 480p / 360p 画质选择（2.5.0、2.5.2、2.8.18）。
- 文件管理支持多选批量删除 / 移动 / 复制 / 重命名、一键清空 `TeslaCam/`（保留目录结构、不动 Boombox / Wraps），U 盘管理模式 5 分钟无操作自动恢复导出（2.8.0）。
- 统一归档规则、配置传递与跨进程锁，OTA 升级可同步带上配套脚本（2.7.0）。

## 导出水印与飞书推送

- 导出：多路合成按原片 4:3 取格子**不留黑边**，原画单路真出 1280×960 + 源帧率，无遥测（停车哨兵）也带时间地点水印；水印恢复播放器同款并加 AP 方向盘图标，iOS / 微信可直接播放 mp4（2.8.13~2.8.19）。
- 缺中文字体不再静默导出「没水印的视频」：导出面板显示字体状态，提供一键安装 / 上传，缺字体直接拦下（2.8.19）。
- 飞书：封面卡片 / 触发前 5 秒短视频（可烧行车信息水印），导出弹窗可直接推送；修复重启后误推几天前的旧事件、转码并发闸门覆盖推送链路（2.4.1、2.4.6~2.4.8）。

## 在线更新、安全与界面

- OTA：7 个镜像源并发竞速 + GitHub API 实时兜底，校验 → 备份 → 原子替换 → 自动重启 → 一键回滚，可勾选自动更新；`no-store` + 版本自检修掉「升级后手机还是旧界面」（2.8.2、2.8.7、2.8.13）。
- 安全加固：Basic 认证同样纳入 8 次 / 10 分钟限速、`auth.conf` 损坏拒绝启动、JSON 体积 / 超时 / 并发上限、HTTPS 反代 Cookie 自动 `Secure`、补齐 DELETE 接口鉴权（2.8.3、2.8.5）。
- 界面：新增 10 种语言（2.4.0）、移动端顶栏 / 页签重构与单行分段控件（2.6.0、2.8.16）、设置页「账号 / 涂装 / 锁车音」子页签、日期与触发原因胶囊筛选、推送配置敏感字段默认打码（2.3.1）。

## 升级须知

- 网页 **设置 → 更新** 一键升级或开启自动更新；2.8.12 及更早版本若连检查都失败，按 README「检查更新失败」手动覆盖一次即可回到自动更新。
- 升级不动录像归档与配置。**预置 exFAT 只作用于新部署 / 重装**，已有数据的镜像不会被覆盖。
- 行为变化：默认画质 480p、默认单路播放、行车记录不预热。想看原画在画质里选「原画」即可，点开行车记录仍会按需转码。
