## 2026.11.25.002 — 2026-11-25

**问题修复**

- 修复从老版本升级时 `scripts/install-f50.py` 直接退出「发现已有路径 /opt/tesla-sentry」：现在检测到已有安装（包括早年没有 `installation.json` 标记的安装）会改为原地升级，只替换程序、离线运行环境与启动脚本，镜像、录像、`auth.conf`、`settings.json`、通知配置与上传素材全部保留。
- 升级时视频与日志路径沿用旧配置，不会因为参数默认值变化把归档改到别的挂载点；`TSF_FFMPEG` / `TSF_FFPROBE` 按本次探测结果刷新。
- 升级前先用新程序跑 `--ota-check` 自检，替换后重启 `tesla-live` 与 `tesla-viewer`；任一步失败自动回滚旧程序、旧配置与定时任务。

**优化改进**

- 旧程序备份为 `/opt/tesla-sentry.bak-<时间>`，旧配置备份为 `/etc/tesla-sentry.conf.bak-<时间>`；校验通过后只保留程序，旧缓存目录随备份释放，不在卡上多占一份。

## 2.8.52 — 2026-11-24

**优化改进**

- 新增「最近1小时记录」与哨兵事件重复片段的自动合并：车机发生哨兵事件时会把最近几分钟的片段从 `RecentClips` 复制进 `SentryClips`，盒子里原本存两份完全相同的 mp4；现在把 `SentryClips` 中那份替换为指向 `RecentClips` 的硬链接（同一 inode），这段重叠时间只占一份数据块。`RecentClips` 按 1 小时滚动删除后，`SentryClips` 的硬链接继续持有数据，回放与保留期不受影响。
- 合并前依次比对文件大小、首尾 1 MiB 采样与全量 SHA-256，确认内容完全一致才替换，不会把不同片段误合并。
- 默认每 30 分钟检查一次，只处理最近 3 小时内有写入的事件目录，单轮最多校验 4 GiB；可用 `TSF_DEDUP_INTERVAL` / `TSF_DEDUP_MAX_MB` / `TSF_DEDUP_WINDOW_MIN` 调整，`TSF_DEDUP_INTERVAL=0` 可关闭。
- 合并过程使用临时硬链接 + 原子 rename，并在事件目录执行 fsync；与归档清理、用户删除并发时失败即跳过，不会留下半成品文件。

## 2.8.51 — 2026-11-24

**功能新增**

- 推送新增微信提醒（爱语飞飞 iyuu.cn）：可只开微信，也可与飞书同时推送；设置页新增接口选择、Token 与开关。
- 设置 → 账号支持修改网页登录用户名：需当前密码确认，改完自动用新用户名重新登录，其它设备旧会话失效。
- 设置 → 更新支持选择更新源：`baicyber/tesla-sentry-f50` 或 `jiaoting/tesla-sentry-f50`，并可选择 Branches 分支（列表从 GitHub 实时拉取），保存在 `ota-target.json`。
- 行车记录与「最近1小时记录」新增从车机 U 盘镜像同步 `event.json`，行车记录归档也会带上该文件。
- 播放页顶部（摄像头信息之后）居中显示动画 HUD：方向盘随角度转动、左右转向灯、加速/减速能量条、车速与挡位；手机端压缩为一条，不再占用视频画面。
- 「存储分配」新增「运行诊断」：检查目录可写、ffmpeg 编码器/解码器、各热区温度，并真实抽帧与编码 2 秒样本，输出设备端 ffmpeg 原始报错。

**问题修复**

- 修复中兴 F50（MU300 / OpenWrt）已安装 ffmpeg 仍无法转码、没有缩略图：4G CPE 的 `thermal_zone` 混有 modem / PA / WiFi 热区（常年 80~95°C），此前取全局最高温导致被永久判定过热、转码直接停摆；现在只取 SoC 热区，找不到 SoC 热区时排除外设并取中位数。
- 持续高温超过 10 分钟且未达危险温度时，改为单核慢速编码，不再永久禁用转码。
- `TSF_FFMPEG` / `TSF_FFPROBE` 指向的文件因固件升级丢失时，自动回退到系统路径，不再静默失效。

## 升级须知

- 网页 **设置 → 更新** 可一键升级或开启自动更新；升级只替换程序与配套脚本，不动录像归档、`auth.conf`、`storage.json` 与 `/etc/tesla-sentry.conf` 中的业务配置。
- 2.8.48 起视频存储统一由 `TSF_VIDEO_ROOT` 派生，旧配置会自动迁移；手动改过 `TSF_IMG` / `TSF_ARCHIVE` 的设备请在「设置 → 存储分配 → 存储路径」确认一次。
- 升级到 2.8.47 及以上后如需让「镜像解析失败自动重试」生效，请重启一次设备（OTA 完成后通常已自动重启）。
- 行为变化：默认画质 480p、默认单路播放、行车记录不预热。想看原画在画质里选「原画」即可，点开行车记录仍会按需转码。
