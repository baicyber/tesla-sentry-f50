- 更新记录改为显示最近 3 个版本；空间校验补上缓存上限，最不利情况下空闲不会低于安全预留。

## 2026.11.25.031 — 2026-11-25

**功能新增**

- 存储分配「调整车机 U 盘容量」新增「格式化 U 盘」：按当前容量重建空白 exFAT，清空镜像内全部内容、归档区保留。车机上格式化 U 盘后网页一直提示镜像未就绪、镜像损坏或调整容量失败时，可一键恢复成车机能识别的 U 盘。
- 格式化与调整容量共用断连、重建、校验与回滚流程；完成后立即失效用量缓存，无需重启。

**问题修复**

- 修复车机上格式化 U 盘后网页、文件管理与在线同步一直提示「镜像未就绪（车机格式化中）」：车机格式化会写入 MBR/GPT 分区表，卷从分区起始扇区开始，原实现只按 0 偏移识别。现在支持整盘、MBR、GPT 与非常规对齐位置（分区表损坏时按 exFAT 签名兜底扫描）。
- 修复 GPT 分区表项读取偏移少了 `512`，导致 GPT 布局始终识别失败。
- 车机 U 盘挂载不再强依赖 `loopNp1` 分区节点：内核未生成节点时改用 `losetup -o 偏移` 或 `mount -o offset=` 直接挂载，格式化完成后即可读取。
- 在线同步解析镜像同步支持卷偏移，并按镜像实际大小判断文件变化，避免每次循环反复重开。

**优化改进**

- 取消车机 U 盘自动清理：移除「车机 U 盘自动清理」「清理时保留最近」设置项、后台清理逻辑及相关环境变量说明；`TSF_USB_CLEAN_PCT` / `TSF_USB_CLEAN_DAYS` 加入废弃配置，启动整理时自动从 /etc/tesla-sentry.conf 清理。车机 U 盘改由车机自身循环覆盖，网页不再删除镜像内旧事件。

## 升级须知

- 网页 **设置 → 更新** 可一键升级或开启自动更新；升级只替换程序与配套脚本，不动录像归档、`auth.conf`、`storage.json` 与 `/etc/tesla-sentry.conf` 中的业务配置。
- 2.8.48 起视频存储统一由 `TSF_VIDEO_ROOT` 派生，旧配置会自动迁移；手动改过 `TSF_IMG` / `TSF_ARCHIVE` 的设备请在「设置 → 存储分配 → 存储路径」确认一次。
- 升级到 2.8.47 及以上后如需让「镜像解析失败自动重试」生效，请重启一次设备（OTA 完成后通常已自动重启）。
- 行为变化：默认画质 480p、默认单路播放、行车记录不预热。想看原画在画质里选「原画」即可，点开行车记录仍会按需转码。
