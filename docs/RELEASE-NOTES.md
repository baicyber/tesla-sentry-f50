## 2026.11.27.044 — 2026-11-27

**文档优化**

- README 扩充「后台优化」章节并改名为「后台优化（性能 · 加载 · 磁盘占用 · 功能）」，强调所有优化都在设备端后台常驻执行、网页关着 / 电脑关机也照常跑；新增「磁盘占用优化」子节，说明稀疏 exFAT 镜像按实际写入计占用、`st_blocks` 真实占用统计、跨分类硬链接去重（`dedupe_archive_clips`）、孤儿转码缓存清理（`prune_orphan_transcodes` + `res_cleanup`）、`.pruned` 墓碑防回灌、位图幽灵占用回收（`reclaim_ghost_allocations`，设 `TSF_RECLAIM_MIN_MB` 为正值启用，默认关闭）、安全预留默认 10 G 与暂停线默认 4 G 的兜底逻辑。
- 新增「功能与生命周期优化」子节：在线只读同步（`tesla-live-sync` 不挂载镜像只读解析 exFAT）、外置卡 / U 盘操作前联动停止同步与释放占用、ext4 格式化写回 UUID、默认目录自愈、行车遥测直读码流 SEI；播放加载补充多画面 250 ms 同步校正，转码性能补充 `MEDIA_ACTIVE` 归零才预转，网络与稳定性补充自动升级仅在无人看视频时进行。

## 2026.11.27.043 — 2026-11-27

- 修复车机上格式化后的镜像无法继续在线同步的问题（与上条同源，OTA 更新后重启设备生效）。

**优化改进**

- 归档总上限设为 0 时，「最近1小时监控」仍按滚动窗口清理，行车记录容量限制独立生效。
- 视频缓存迁移到安装目录 `cache/` 下，按用途分为 `res-cache` / `thumbs` / `stitch-tmp` / `tel-cache`，并支持 `TSF_CACHE` 覆盖。
- 归档视频响应增加 `Cache-Control` 与 `ETag`，重复查看和拖动时减少回源，提升加载速度。
- F50 的 FFmpeg 改用 `apk add ffmpeg`（`/usr/bin`），修正 aarch64 架构判断；配置中的 `TSF_FFMPEG` / `TSF_FFPROBE` 固定指向 `/usr/bin`。
- 转码中提示「仍在转码 X%」，预览分片显示「正在转码 X%」；失败时提示原因并可一键播放原画。

## 升级须知

- 网页 **设置 → 更新** 可一键升级或开启自动更新；升级只替换程序与配套脚本，不动录像归档、`auth.conf`、`storage.json` 与 `/etc/tesla-sentry.conf` 中的业务配置。
- 2.8.48 起视频存储统一由 `TSF_VIDEO_ROOT` 派生，旧配置会自动迁移；手动改过 `TSF_IMG` / `TSF_ARCHIVE` 的设备请在「设置 → 存储分配 → 存储路径」确认一次。
- 升级到 2.8.47 及以上后如需让「镜像解析失败自动重试」生效，请重启一次设备（OTA 完成后通常已自动重启）。
- 行为变化：默认画质 480p、默认单路播放、行车记录不预热。想看原画在画质里选「原画」即可，点开行车记录仍会按需转码。
