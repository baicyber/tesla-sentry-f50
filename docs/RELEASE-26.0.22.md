# 26.0.22

本次将已部署的 26.0.22 查看器功能整合到上游 2.8.46，保留上游安装器、FFmpeg 路径配置、多文件 OTA、USB 启动协调、六路归档、存储恢复和多段推送修复。

## 主要变化

- 预览分片在编码完成首片后即可返回，按播放需要与缓冲余量调度后续请求；四路保持同步，失败镜头可单独重试。
- 播放进度条显示浏览器实际缓冲区间；同片段切换单路与四路时复用视频缓冲。
- 原画四路支持下一分钟预加载，媒体发送允许正常暂停与缓冲满窗后继续读取；CGNAT 直连地址默认使用原画。
- 桌面标签页切回前台后恢复预缓冲，支持 ManagedMediaSource 的浏览器可使用主动预缓冲与缓冲裁剪。
- 固定行车状态栏及系统读数布局，显示播放速度与累计流量；改善主题首帧、录像列表加载及手机布局。
